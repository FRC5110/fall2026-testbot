# Code structure: fall2026-testbot

## Overview

- **Robot:** fall 2026 swerve test robot (drivetrain only, no mechanisms yet).
- **Language and library:** Java 17, command-based, WPILib 2026.2.1 (GradleRIO 2026.2.1).
- **Drivetrain:** CTRE Phoenix 6 swerve (vendordep `Phoenix6-26.3.0.json`), generated by the Tuner X Swerve Project Generator. Four modules, each with a drive motor and a steer motor on TalonFXS controllers (NEO, JST), a CANcoder, and a Pigeon 2 gyro.
- **Where things are:**
  - Drivetrain settings, gains, gear ratios, and CAN IDs: `src/main/java/frc/robot/generated/TunerConstants.java` (regenerate with Tuner X; don't rename its constants).
  - Driver controls and the autonomous routine: `src/main/java/frc/robot/RobotContainer.java`.
  - Other robot-wide constants: `src/main/java/frc/robot/Constants.java`. New CAN IDs go here with names ending in `_CAN_ID`.
  - Drivetrain doc: [subsystems/CommandSwerveDrivetrain.md](subsystems/CommandSwerveDrivetrain.md).
