## Purpose
Four-module swerve drivetrain. Drives the robot field-centric from the driver's Xbox controller and runs the autonomous routine. Generated by the CTRE Tuner X Swerve Project Generator; settings live in `src/main/java/frc/robot/generated/TunerConstants.java`.

## Control
- Drive and steer closed-loop output: voltage. Steer feedback: FusedCANcoder (falls back to RemoteCANcoder without a Phoenix Pro license).
- Steer gains: kP 100, kI 0, kD 0.5, kS 0.1, kV 2.62, kA 0.
- Drive gains: kP 0.1, kI 0, kD 0, kS 0, kV 0.122. Values from Tuner X; no tuning recorded for this robot yet.
- Speed at 12 V: 4.64 m/s (`kSpeedAt12Volts`, must be measured). Driver max speed is 1.0 x that; max turn rate 0.75 rotations/s; 10% deadband (`RobotContainer`).
- Driver requests use open-loop voltage for the drive motors (`DriveRequestType.OpenLoopVoltage`).

## Commands that use it
| Command | Trigger | What it does |
| --- | --- | --- |
| `applyRequest(FieldCentric)` | Default command | Field-centric driving from left stick (translate) and right stick X (rotate) |
| `applyRequest(SwerveDriveBrake)` | A held | Locks wheels in an X |
| `applyRequest(PointWheelsAt)` | B held | Points wheels in the left-stick direction |
| `runOnce(seedFieldCentric)` | Left bumper | Resets field-centric heading |
| `sysIdDynamic` / `sysIdQuasistatic` | Back or Start + Y/X held | SysId translation routine (Procedure 7) |
| `applyRequest(Idle)` | Robot disabled | Applies neutral mode |
| `getAutonomousCommand()` | Autonomous | Resets heading, drives forward at 0.5 m/s for 5 s, then idles |
